6. Cierre de caja

CROZZO CLOSE CAJA ORDER SESSION
        │
        ├──► crozzoSyncPosRuntimeCritical('slot_paid'/'post_cobro')
        │
        ├──► closedSlots = true
        │
        ├──► runtime push (pushMesaRows)
        │
        └──► UI: arqueo wizard (conteo → calcular → confirmar)
                  │
                  ├──► fondo inicial
                  ├──► gastos
                  ├──► efectivo contado
                  └──► diferencia vs ventas calculadas

Conexión: El cierre dispara sync runtime y marca slots como cerrados. Si closedSlots no se setea, el vaciado remoto puede dejar carrito stale (KI-018).
